# 온열 위험도 대시보드

`코드 예시.txt`의 WBGT 계산 흐름을 다중 작업자용 Streamlit 화면으로 옮긴
온열 위험도 대시보드입니다. 각 작업자 기기는 최초 1회 작업자 번호, 이름,
고정 프로필, 현재 심박수, 온열지수(WBGT)를 등록하고, 관리자 기기는 모든
작업자의 현재 위험도를 한 화면에서 확인합니다.
위험도 단계는 `안전`, `주의`, `경고`, `위험` 4단계로 표시됩니다.
휴대폰에서 `알림 활성화`를 누르면 `경고` 이상 단계에서 브라우저 알림, 소리, 진동을 시도합니다.

## 대시보드 실행

```powershell
python -m pip install -r requirements.txt
python -m streamlit run cloud_app.py
```

같은 링크라도 기기별로 역할이 나뉩니다.

- 관리자 노트북: `관리자 등록` 탭에서 관리자 코드를 입력하면 관리자 화면과 데이터센터를 볼 수 있습니다.
- 작업자 기기: 처음 접속하면 작업자 등록 화면이 나오고, 등록 후에는 해당 작업자 화면으로 바로 들어갑니다.
- 기존 작업자 기기: 같은 브라우저로 다시 접속하면 저장된 기기 ID를 통해 기존 작업자로 판단합니다.

기기 ID는 브라우저 쿠키에 저장되어 기본 주소로 다시 접속해도 같은 기기로 인식합니다.
다른 브라우저나 시크릿 모드에서는 별도 기기로 취급됩니다. Render의 임시 저장소에
저장된 작업자·기기 정보는 서비스 재시작 또는 재배포 시 사라질 수 있으므로,
장기 보존이 필요하면 영구 저장소를 연결해야 합니다.

기본 관리자 코드는 `ADMIN-2026`입니다. 배포 환경에서는 `WGBT_ADMIN_CODE` 환경변수로
원하는 코드로 바꿀 수 있습니다.

## 관리자 화면

관리자 화면에는 세 개의 탭이 있습니다.

- `작업관리자 대시보드`: 등록된 모든 작업자의 위험도를 카드 형태로 확인하고, `상세 보기`로 개별 작업자 정보를 확인합니다.
- `작업자 등록/측정 입력`: 작업자 번호와 이름, 프로필, 현재 심박수, WBGT를 한 창에서 등록하거나 수정합니다.
- `데이터센터`: 측정 저장 시점에 `경고` 또는 `위험`으로 감지된 기록을 시간순으로 확인합니다.

관리자가 입력한 작업자 정보도 작업자별 현재 상태로 저장되므로, 센서 연동 전에는
이 탭을 수동 입력 창처럼 사용할 수 있습니다.

## 휴대폰 알림

대시보드를 휴대폰에서 열고 `알림 활성화` 버튼을 한 번 누릅니다. 이후 위험도
단계가 `경고`, `위험` 중 하나가 되면 대시보드가
브라우저 알림, 소리, 진동을 시도합니다.

휴대폰 OS 푸시 알림은 브라우저 보안 정책상 HTTPS 주소에서만 정상 지원되는
경우가 많습니다. 로컬 `http://IP주소:8501` 접속에서는 소리와 진동은 가능해도
OS 알림 권한이 제한될 수 있습니다.

## PC 명령 입력

1차 버전의 단일 작업자 입력 스크립트는 남아 있지만, 2차 다중 작업자 화면의
권장 사용 방식은 `cloud_app.py` 안의 관리자/작업자 입력 탭입니다.

프롬프트에 값을 직접 입력합니다.

```powershell
python input_measurement.py
```

한 줄 명령으로도 갱신할 수 있습니다.

```powershell
python input_measurement.py --heart-rate 144 --wbgt 32.4
```

명령으로 프로필까지 같이 바꿀 수도 있습니다.

```powershell
python input_measurement.py --heart-rate 144 --wbgt 32.4 --age 38 --weight 82.5 --sex female
```

현재 입력값은 `data/current_measurement.json`에 저장됩니다. 다중 작업자 앱의
런타임 데이터는 `data/devices.json`, `data/workers.json`, `data/risk_events.json`에
저장되며, 이 파일들은 배포/커밋 대상에서 제외됩니다.

위험도 계산은 제공된 WBGT 예시 로직을 유지합니다. 화면의 휴식 시간과 행동
양식은 현장 판단을 돕는 참고 권고이며 작업 조건, 증상, 공식 폭염 안내와 함께
확인해야 합니다.

## HTTPS 배포

어디서나 접속 가능한 HTTPS 주소가 필요하면 `cloud_app.py`를 배포합니다.
Render 배포 설정은 `render.yaml`에 들어 있고, 자세한 절차는
`DEPLOY_RENDER.md`를 참고하세요.
